# Portfolio Copilot - Modules & Thin Slice Design

## 1. התרחיש הראשון (Thin Slice) - בוצע והורחב
- **קלט**: סכום להפקדה חודשית (למשל 5,000 ₪) ויעדי הקצאה (למשל 80% מדד מניות, 20% אג"ח).
- **פעולה**: חלוקת ההפקדה לפי המשקלים, ללא חריגה מהתקציב.
- **פלט**: כמה שקלים לקנות מכל נכס.
- **היום**: הפונקציה אינה Mock. היא אופטימיזציית SciPy (SLSQP) שמושפעת מהפרופיל (רמת סיכון, תקרת משקל לנכס).

## 2. מודולים ואחריות (מצב נוכחי)
| מודול | אחריות | AI? |
| --- | --- | --- |
| `schemas.py` | מבני נתונים (Pydantic): פרופיל משקיע, מיזוג פרופיל בטוח | לא |
| `db.py` | SQLite: משתמשים, פרופילים, החזקות, הפקדות, מסמכים, תוכניות, אירועי משכורת | לא |
| `tools.py` | תבניות סיכון, קריאת CSV, מחירי שוק, אופטימיזציה (SciPy), תכנון עסקאות | לא (קוד דטרמיניסטי) |
| `agent.py` | פרומפט המערכת, שיחה מרובת תורות, לולאת קריאה לכלים, חילוץ JSON, תיקון פלט | כן (LLM) |
| `agent_tools.py` | הכלים שהסוכן יכול לקרוא: `get_portfolio`, `plan_deposit`, `get_documents`, `propose_plan`, `salary_received`, `search_documents` | קריאה לכלים |
| `rag.py` | חיתוך מסמכים, embeddings, מאגר וקטורי (Chroma), שליפת קטעים | כן (embeddings) |
| `documents.py` | קריאת תלוש שכר (PDF) | כן (חילוץ + אימות) |
| `fund_reports.py` | קריאת דוחות קרנות (השתלמות, גמל, פנסיה) | כן (חילוץ + אימות) |
| `intake.py` | שאלון היכרות ורמת סיכון | חוקים (ללא LLM) |
| `picture.py` | תמונת מצב מהמסמכים והפרופיל | לא |
| `analysis.py` | ניתוח וניסוח הנחיה לפרופיל, עם גבולות בקוד ו-fallback | כן (LLM, מוגבל בקוד) |
| `plan.py` | בניית תוכנית חודשית ואישורה | לא |
| `salary.py` | אירוע "נכנסה משכורת" | לא |
| `auth.py`, `users.py` | התחברות לפי משתמש | לא |
| `app.py`, `ui.py` | ממשק Gradio בעברית (4 שלבים + טאב שיחה) | לא |

## 3. מה עוד חסר (ראו mvp.md)
שאלון ההיכרות עדיין חוקים ולא שיחה, מאגר ה-RAG ריק מתוכן אמיתי, משיכה אופטימלית וקריאת דוחות משכנתא לא נבנו.
